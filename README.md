# IELTS speaking test

A timed 15-minute IELTS Speaking test that runs entirely in the browser.
Records one audio file per part, captures a transcript, and produces a
report the teacher grades from. No backend, no accounts, no cost.

Question sets and timings are at the top of `index.html`, in the blocks
marked QUESTION BANK and `T`.

Students must use Chrome on a laptop with headphones.
